# Ограничения решения

## Поддерживаемые условия
- Язык: русский (модель русскоязычная).
- Входной формат модели: 16 кГц моно (файлы конвертируются приложением).
- Входные форматы: `.mp3`/`.wav` (минимум), `.ogg`/`.flac`/`.m4a` (graceful).
- `minSdk 26`, устройства с ОЗУ более 4 ГБ.

## Известные ограничения
- **Чанкинг фиксированный (60 с)** — границы не по паузам, слово может резаться на стыке чанков.
- **Диаризация по чанкам**: кластеры нумеруются независимо в каждом 60-с чанке, поэтому
  `speaker_1` в разных чанках длинного файла могут быть разными людьми (нужен глобальный кластеринг).
- **Точность ASR** падает на зашумлённых/музыкальных фрагментах и на чанках > ~90 с.
- Модели бандлятся в APK (~390 МБ) — установка и первый запуск медленные (копирование моделей ~7 с).

## Что не входит в текущую версию
- Чанкинг по паузам (вместо фиксированного 60 с).
- Антиалиасный ресемплер, больше потоков, fp32-энкодер, NNAPI/QNN, собственная сборка sherpa.
- Локальная LLM-постобработка (пунктуация, исправление опечаток).
- Экспорт SRT (JSON реализован, TXT/SRT — потом).

## Риски демонстрации
- Тяжёлые тесты (ASR + диаризация + нагрузка) на эмуляторе x86_64 могут упираться в память;
  на реальном устройстве с аппаратным кодеком — быстрее и без артефактов софт-кодека.

## Дальнейшее развитие
- Согласованная диаризация по всему файлу, чанкинг по паузам.
- Экспорт TXT/SRT, локальная LLM-постобработка.
