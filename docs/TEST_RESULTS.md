# Результаты тестирования

## Покрытие
- **Unit-тесты: 26** — `TimeFormatter`, `Segmenter`, `TranscriptAssembler`, `AudioValidator`.
- **Инструментальные: 20** — UI, ядро ASR, валидация, запись с микрофона, диаризация,
  экспорт JSON, чанкинг, нагрузка.

- **RTF ≈ 0.30–0.39** (вместе с диаризацией) — обработка идёт в ~2.5–3 раза быстрее реального времени.
  Без диаризации ASR-ядро было ~0.22–0.26; диаризация добавляет ~40–60 % времени.
- Диаризация выполняется **по 60-с чанкам**: на многоголосных записях нумерация спикеров
  локальна для чанка (`speaker_1` в разных чанках — потенциально разные люди).
