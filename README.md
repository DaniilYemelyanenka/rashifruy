# «Расшифруй» — офлайн-распознавание речи с диаризацией

Приложение для Android: записанный или выбранный звук превращается в расшифровку
с таймкодами и указанием, **кто из говорящих какую реплику произнёс**.

Вся обработка выполняется только на устройстве (офлайн) — сеть не используется ни на каком этапе.

## Возможности
- Загрузка аудиофайла (`.mp3`, `.wav` минимум; `.ogg`, `.flac`, `.m4a`)
- Запись звука с микрофона
- Распознавание русской речи (GigaAM v3 RNN-T через sherpa-onnx)
- Диаризация говорящих — подписи «Спикер N»
- Экспорт результата в JSON (каноничная схема `{transcript: [{speaker_id, start_ms, end_ms, text}]}`)

## Структура
- `src/mobile/android/` — исходный код приложения (см. инструкцию по сборке)
- `docs/` — архитектура, ограничения, результаты тестов, ТЗ
- `artifacts/demo/` — демо-материалы (скриншоты/видео)
- `artifacts/test-results/` — метрики нагрузочного тестирования
- `config/` — конфигурация
